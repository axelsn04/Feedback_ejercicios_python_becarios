# Python Data Engineering Exercises

A series of practical exercises designed for developers who already know Python and want to develop systems thinking around data: storage, querying, pipelines, and serving.

The goal is not data science or statistics. The goal is to train engineers to make informed decisions about how data is stored, accessed, transformed, and served — and to back those decisions with measurements.

---

## Exercises

Each exercise lives in its own folder with a dedicated `README.md` covering the problem, requirements, and deliverables.
